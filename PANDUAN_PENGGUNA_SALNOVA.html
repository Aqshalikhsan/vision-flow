Dataset, upload, anotasi, dan versioning

2 · DATASET
A. Klik Upload data dari Overview; atur detik per frame untuk video.
B. Kelola gambar, status anotasi/review, dan split train-valid-test.

Upload gambar/video besar

  1. Klik Upload data, pilih gambar atau MP4/MOV/WebM.
  2. Untuk video, atur Detik per frame; nilai 1 ≈ satu frame per detik.
  3. Tunggu upload dan pemrosesan 100%; jangan reload atau tutup tab.
File 200 sampai 300 MB didukung. File dikirim bertahap sekitar 8 MB per bagian, lalu server menyusunnya kembali. Video tidak dipotong manual dan isinya tetap satu file utuh.

Kelola dataset

  • Filter status, review, dan split.
  • Import ZIP anotasi: YOLO, COCO, VOC, LabelMe, CVAT.
  • Export annotated ZIP atau jalankan auto-label.
  • Split awal umum: 70% train, 20% valid, 10% test.
E. Health & Jobs memeriksa kualitas dataset dan pekerjaan yang sedang berjalan.

Rescan dataset, lalu tindak lanjuti file duplikat, blur, resolusi rendah, label kosong, atau class yang tidak seimbang.

C. Annotator: class kiri, area kerja tengah, daftar anotasi kanan.

Anotasi

  1. Pilih class dan alat box/polygon/mask/keypoint.
  2. Buat label rapat dan konsisten; cek daftar kanan.
  3. Pastikan Saved sebelum pindah gambar.

Shortcut: Ctrl+Z/Y undo/redo · Ctrl+C/V salin/tempel · arrow menggeser · Delete menghapus.

D. Buat versi immutable sebelum training.

Quality & version

Di Health & Jobs, cek duplikat, blur, resolusi rendah, label kosong, dan ketidakseimbangan class. Buat Version: pilih split, resize, augmentasi, nama, dan catatan. Perubahan anotasi berikutnya memerlukan versi baru.

Auto-label hanyalah draft. Review sampel dan Accept/Reject hasilnya sebelum versioning.

Inference, deployment, workflow, dan laporan bug

4 · OPERASIONAL
A. Deploy & test dengan hasil deteksi dan confidence.

Inference

  1. Buka Deploy pada project dengan model Ready.
  2. Pilih Image, Webcam, Batch, atau Video.
  3. Masukkan media, atur confidence, lalu cek hasil.
  4. Unduh media beranotasi atau report.

Naikkan threshold untuk mengurangi false positive; turunkan bila objek benar banyak terlewat. Webcam wajib HTTPS. Video diproses dengan sampling dan UI membatasi hingga 300 frame.

API key wajib dirahasiakan. Endpoint 127.0.0.1 hanya berlaku pada host yang sama; integrasi eksternal memakai endpoint/domain dari admin.
B. Workflow menghubungkan input, inference, condition, dan output.

Workflows & Advance

Rangkai node, hubungkan sesuai arah data, simpan, test run, lalu cek run history. Workflow dapat diimpor/diekspor JSON dan dijadwalkan. Advance menyediakan smart segmentation, model-assisted auto-label, batch mask, video propagation, dan quality review.

Checklist produksi

  • Dataset bersih, anotasi direview, version terkunci.
  • Model diuji pada media lapangan dan threshold ditetapkan.
  • Stage production, monitoring, API key, dan rollback siap.
  • Backup sebelum perubahan besar; restore mengganti workspace.
Jangan langsung menerima seluruh hasil otomatis. Review sampel dan simpan jejak version/model yang dipakai.
C. Ikon bantuan/laporan mengambang di kanan bawah aplikasi.

Jika menemukan bug

  1. Klik ikon laporan/bantuan di pojok kanan bawah.
  2. Pilih fitur Aduan bug.
  3. Pilih Area kendala dan tingkat Dampak.
  4. Isi ringkasan serta detail, lalu klik Kirim aduan.
Sertakan: langkah sebelum bug, hasil yang muncul, hasil yang diharapkan, nama project/model, jenis dan ukuran file, waktu kejadian, browser, serta pesan error. Halaman aktif tercatat otomatis.

Untuk worker: sebutkan nama worker, status online/offline, apakah PC baru restart, dan apakah shortcut manual sudah dijalankan.

Alur ringkas: domain → project → upload → annotate → version → train → models → inference → production. Jika tersendat, laporkan melalui ikon dan fitur Aduan bug.
